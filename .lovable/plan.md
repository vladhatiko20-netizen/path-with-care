## Что было сделано в прошлый раз
В `src/styles.css` я добавил правила для `.yarl__slide_captions_container` (тоньше затемнение, мягкий градиент) и `.yarl__slide_description` (margin 2px). Но эти правила влияют только на сам контейнер подписи — они не сдвигают подпись вниз относительно фотографии, потому что YARL по умолчанию центрирует изображение в слайде, и контейнер подписи прижат к нижней кромке слайда. Уменьшение паддингов сделало полосу тоньше, но визуально текст остался почти на том же месте.

## Новый план (мобильный лайтбокс)

### 1. Фотография крупнее — убрать боковые поля
По умолчанию YARL даёт `.yarl__slide` padding ~16px по бокам. Уберём их на мобильных, чтобы фото шло почти до краёв экрана:
```css
@media (max-width: 767px) {
  .yarl__slide { padding: 0 !important; }
}
```

### 2. Поднять фотографию вверх и дать ей больше высоты
Сейчас фото центрировано вертикально между верхом экрана и полосой миниатюр, и подпись «парит» поверх нижней части фото. Сделаем мобильный слайд вертикальной колонкой (фото сверху в полную ширину, подпись отдельным блоком ниже фото — НЕ поверх):
```css
@media (max-width: 767px) {
  .yarl__slide {
    display: flex;
    flex-direction: column;
    justify-content: flex-start; /* фото к верху */
    align-items: center;
  }
}
```

### 3. Подпись — снизу, под фото, тёмная плашка вместо градиента поверх фото
Поскольку фото больше не перекрывается подписью, заменим градиент на простую полупрозрачную плашку, прижатую к низу, и сдвинем её ещё ниже:
```css
@media (max-width: 767px) {
  .yarl__slide_captions_container {
    position: absolute !important;
    bottom: 0 !important;
    padding: 4px 12px 8px !important;
    background: rgba(0,0,0,0.55) !important; /* ровная плашка, без градиента */
  }
  .yarl__slide_description {
    margin: 0 !important;
    font-size: 14px !important;
    line-height: 1.3 !important;
  }
}
```

### 4. Desktop не трогаем
Все правки — только внутри `@media (max-width: 767px)`. Desktop-вариант (`.lb-desktop-caption`, `min-width: 768px` блок) остаётся как есть.

## Технические детали
Все изменения — в `src/styles.css`, в одном новом мобильном медиа-блоке. Никакого JS/React, никаких изменений в `LightboxCaption.tsx`. После применения: на телефоне фото будет от края до края по ширине, прижато к верху, а подпись окажется компактной полоской у нижней кромки фото, прямо над миниатюрами.

## Риски
Если конкретное фото имеет очень вытянутую вертикальную пропорцию, при «фото к верху» снизу может остаться больше пустого чёрного пространства между фото и подписью. Если это будет мешать — на следующем шаге можно прижать подпись прямо к низу фото через `align-self` на каптион-контейнере. Сейчас закладываю самый простой вариант.
