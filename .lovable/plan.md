## Проблема
На мобильной версии страницы `/admin/destinations` заголовок «Направления» и кнопки находятся в одной строке (`flex items-center justify-between`). Из-за этого кнопки «Импорт из JSON» и «+ Новое направление» уезжают за правый край экрана.

## Решение
Изменить только верхний блок на странице `src/routes/_admin/admin.destinations.index.tsx`:

1. На мобильных (`< md`):
   - Заголовок «Направления» — по центру, на отдельной строке.
   - Под ним — обе кнопки в ряд, по центру, с `flex-wrap`, чтобы умещались. Порядок: «Импорт из JSON», затем «Новое направление» (как просил пользователь).
2. На десктопе (`md+`) — оставить текущий вид (заголовок слева, кнопки справа).

Технически: заменить `flex items-center justify-between` на адаптивный контейнер — `flex flex-col items-center gap-3 md:flex-row md:justify-between` для внешнего блока, и `flex flex-wrap justify-center gap-2` для группы кнопок.

Никаких других файлов и страниц не трогаем. Логика и тексты кнопок не меняются.
