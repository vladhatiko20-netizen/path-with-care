Мы сделаем переключатель статуса публикации ("is_published") интуитивно понятным и интерактивным.

### Предлагаемое решение

1. **Импорт иконок**:
   Добавим иконки `Eye` (Глаз) и `EyeOff` (Перечеркнутый глаз) из библиотеки `lucide-react` в файл `src/routes/_admin/admin.destinations.index.tsx`.

2. **Интерактивная кнопка-переключатель (Pill/Badge)**:
   Вместо статичной кнопки мы сделаем ее интерактивной при наведении на десктопе, используя возможности Tailwind CSS (`group` и `hover:`).

   * **Если направление опубликовано (`is_published: true`)**:
     * **В обычном состоянии**: Зеленый фон (`bg-green-100 text-green-800`), иконка `Eye` (зеленая), текст "Опубликовано".
     * **При наведении (`hover:` на десктопе)**: Мягкий розово-красный фон (`hover:bg-rose-100 hover:text-rose-800`), иконка меняется на `EyeOff` (розовую), текст меняется на "Скрыть".
     * Добавим класс `cursor-pointer`.

   * **Если направление скрыто (`is_published: false`)**:
     * **В обычном состоянии**: Серый фон (`bg-muted text-muted-foreground`), иконка `EyeOff` (серая), текст "Скрыто".
     * **При наведении (`hover:` на десктопе)**: Зеленый фон (`hover:bg-green-100 hover:text-green-800`), иконка меняется на `Eye` (зеленую), текст меняется на "Опубликовать".
     * Добавим класс `cursor-pointer`.

### Как это будет реализовано в верстке:
Мы применим класс `group` к кнопке, чтобы управлять видимостью элементов внутри нее:
- Для иконки "текущего состояния": `<Icon className="group-hover:hidden w-4 h-4" />`
- Для иконки "состояния после клика" (при наведении): `<Icon className="hidden group-hover:inline w-4 h-4" />`
- Для текста "текущего состояния": `<span className="group-hover:hidden">Текст</span>`
- Для текста "состояния после клика": `<span className="hidden group-hover:inline">Текст</span>`

Это решение является чистым, не требует введения дополнительного React-state для отслеживания наведения, отлично работает на мобильных (где нет hover) и выглядит очень профессионально на десктопах.
