# Исправление ссылок направлений на главной

## Проблема
На главной странице (`src/routes/index.tsx`, строка 176) хардкод: только карточка с `slug === "bari"` ведёт на `/destinations/bari`, остальные семь — на общий каталог `/destinations`. Поэтому Молдова ведёт «через» каталог.

## Решение
Сделать каждую карточку умной: если slug направления опубликован в БД — ссылка ведёт прямо на `/destinations/$slug`; если нет (направление ещё не готово) — ведёт на каталог `/destinations`, как сейчас.

## Технические шаги

1. **`src/routes/index.tsx`**
   - Подгрузить список опубликованных slug'ов через уже существующий `listPublicDestinations` (`src/lib/destinations.functions.ts`) с помощью `useQuery` (без Suspense, чтобы главная не блокировалась, если БД ответит медленно).
   - Из ответа собрать `Set<string>` опубликованных slug'ов.
   - В `.map` карточек заменить тернарник на:
     ```tsx
     const isPublished = publishedSlugs.has(d.slug);
     <Link
       to={isPublished ? "/destinations/$slug" : "/destinations"}
       params={isPublished ? { slug: d.slug } : undefined}
       ...
     />
     ```
   - Пока запрос грузится — fallback на `/destinations` (безопасно, как сейчас).

2. Ничего больше не трогать: тексты, картинки, дизайн карточек, остальные секции главной — без изменений.

## Что получит пользователь
- Бари → `/destinations/bari` (как сейчас).
- Молдова (после того как ты её опубликовал) → `/destinations/moldova` напрямую.
- Остальные шесть пока не опубликованы — продолжат вести на каталог `/destinations`, пока ты их не заполнишь и не опубликуешь. После публикации очередного направления оно автоматически начнёт вести прямо на свою страницу, без правок кода.

## Важное замечание про slug'и
Slug'и на главной захардкожены: `bari, jerusalem, corfu, athos, georgia, romania, ukraine, moldova`. Чтобы автоматика сработала, slug направления в БД должен **точно совпадать** с этими значениями. У `bari` совпадает, у `moldova` — нужно убедиться, что в БД тоже `moldova`. Если ты использовал другой slug (например, `moldova-monasteries`) — ссылка не найдёт совпадение и поведёт в каталог. Если хочешь, могу проверить slug Молдовы в БД до правок.

## Проверка после реализации
1. На главной кликнуть Бари → `/destinations/bari` (напрямую).
2. На главной кликнуть Молдову → `/destinations/moldova` (напрямую, если slug совпал).
3. На главной кликнуть любое неопубликованное (например, Афон) → `/destinations` (каталог).
4. Дизайн карточек не изменился.
