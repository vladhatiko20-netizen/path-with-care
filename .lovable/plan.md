## Цель
Разрешить загрузку фотографий в формате AVIF в админ-панели — в дополнение к JPG, PNG и WEBP. Ничего другого не трогаем.

## Что меняется
Только один файл: `src/components/admin/ImageUpload.tsx`. Этот компонент используется во всех админ-формах (паломничества, направления, святыни, блог, галерея и т.д.), поэтому правка в одном месте автоматически включит AVIF везде.

## Изменения в `src/components/admin/ImageUpload.tsx`

1. **Список разрешённых MIME-типов** — добавить `image/avif`:
   ```ts
   const ALLOWED = ["image/jpeg", "image/png", "image/webp", "image/avif"];
   ```

2. **`<input accept="...">`** — добавить `image/avif`:
   ```tsx
   accept="image/jpeg,image/png,image/webp,image/avif"
   ```

3. **Подсказка под кнопкой** — обновить текст:
   ```
   JPG, PNG, WEBP, AVIF — до 15 МБ. Фото автоматически оптимизируется…
   ```

4. **Логика сжатия (`browser-image-compression`)** — AVIF при пережатии преобразуем в JPEG (как сейчас делается с WEBP), чтобы гарантированно работало во всех браузерах и хранилище. PNG по-прежнему остаётся PNG для сохранения прозрачности. То есть AVIF на входе → JPEG на выходе. Это согласуется с текущей логикой и не требует расширения списка расширений (`ext`).

## Что НЕ меняется
- Дизайн, шрифты, цвета — без изменений.
- Бакет `public-images` и его политики — без изменений (он принимает любые типы, ограничение только на стороне UI).
- Другие компоненты, формы, маршруты — не трогаем.
- Серверные функции — не трогаем.

## Риски
Минимальные. AVIF поддерживается всеми современными браузерами (Chrome 85+, Safari 16+, Firefox 93+). Старый Safari может не уметь декодировать AVIF для предпросмотра — но загрузка и сжатие всё равно отработают, потому что `browser-image-compression` использует Canvas API, который умеет читать AVIF в тех же браузерах, где он поддерживается нативно.

## Проверка после реализации
1. Открыть любую админ-форму с загрузкой фото.
2. Загрузить `.avif` файл — должен пройти валидацию, сжаться и сохраниться (как JPEG) в бакет.
3. JPG/PNG/WEBP продолжают работать как раньше.
