## A — Viber рядом с телефоном на /admin/leads/$id

Файл: `src/routes/_admin/admin.leads.$id.tsx`

Сейчас в строке телефона уже есть пилюля «Viber», но она показывается только когда `isMoldovaPhone(lead.phone)` истинно. Кнопка «Позвонить» (телефонная ссылка) и Viber-пилюля уже являются отдельными `<a>` с независимыми hover-стилями (`hover:bg-accent/5` у телефона, `hover:opacity-80` у Viber) — менять интерактивность не нужно.

Изменение единственное: убрать условие `moldova && …` у Viber-пилюли и оставить только условие, что у заявки есть телефон (оно уже даёт обёртку `lead.phone &&` выше). Пилюля начнёт показываться для всех номеров, а не только молдавских. Стиль, размер, иконка/текст, цвет `#7360F2`, ссылка `viberLink(lead.phone)` — без изменений.

Ничего другого в файле не трогаю.

## B — Пульсирующий красный индикатор в дашборде

Файл: `src/routes/_admin/admin.index.tsx`

Сейчас рядом с заголовком «Заявки» рендерится числовой бейдж `bg-gold` при `unreadCount > 0`. Заменяю его на маленькую красную пульсирующую точку:

```tsx
{unreadCount > 0 && (
  <span
    className="ml-2 inline-block w-2.5 h-2.5 rounded-full bg-[#ef4444] animate-pulse align-middle"
    aria-label={`Непрочитанных заявок: ${unreadCount}`}
  />
)}
```

Никаких других изменений (сайдбар-бейдж в `_admin.tsx` не трогаю, остальные карточки тоже).

## C — Пульсирующий красный индикатор на карточках заявок

Файл: `src/routes/_admin/admin.leads.index.tsx`

В файле сейчас две «точки непрочитанного» (для pilgrimage-карточек и для остальных) — обе `w-2 h-2 rounded-full` с цветом `bg-accent` (терракотовый) и `bg-gold`. Заменяю обе на одинаковый красный пульсирующий индикатор, чуть крупнее текущего:

```tsx
<span
  className="inline-block w-2.5 h-2.5 rounded-full bg-[#ef4444] animate-pulse shrink-0"
  aria-label="Непрочитано"
/>
```

Условие `!r.is_read` и расположение элементов сохраняю. Прочитанные карточки остаются без индикатора. Ничего другого на экране не меняю (бордеры, фоны, кнопки внизу карточек — без изменений).

## Замечания

- `animate-pulse` — стандартный Tailwind-класс, отдельных keyframes добавлять не нужно.
- Цвет задаётся арбитрарным значением `bg-[#ef4444]`, чтобы точно соответствовать red-500 без зависимости от темы.
- Все три изменения независимы и затрагивают только указанные файлы.
