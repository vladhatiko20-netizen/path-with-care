## Что меняем на странице `/destinations/bari`

Только presentation-слой — серверная логика, формы, контент не трогаем.

### 1. Десктоп: уменьшить превью галереи в правой колонке hero

Сейчас: сетка 2×2 квадратных превью на всю ширину правой колонки → каждая плитка получается крупной и колонка по высоте «перерастает» левую hero-картинку.

Меняем на **один ряд из 4 маленьких квадратных превью** над заголовком «О поездке»:
- `grid grid-cols-4 gap-2` вместо `grid-cols-2`
- Ограничим ряд по ширине (`max-w-[70%]`), чтобы превью были компактными и левая hero-картинка визуально доминировала.
- Aspect-ratio оставляем `aspect-square`, рамка `ring-1 ring-gold/30` и hover-эффекты — без изменений.

Итог: высота правой колонки сокращается, нижний край превью не опускается ниже левой hero-картинки. Если фото станет, скажем, 6–8 штук, ряд можно будет расширить или сделать 2 ряда по 4 — но это уже следующий шаг, сейчас 4 шт.

### 2. Мобайл: уменьшить полосу галереи под hero

Сейчас каждое фото `w-[70vw] aspect-[4/3]` — занимает почти весь экран.

Меняем на `w-[45vw] aspect-square` (примерно вдвое уже). На экране одновременно помещаются ~2 фото + край третьего, видно что полоса прокручивается. Сама секция за счёт меньшей высоты тоже станет компактнее.

### 3. Лайтбокс: убрать боковые отступы на мобильном

`yet-another-react-lightbox` по умолчанию даёт паддинг вокруг слайда (`carousel.padding` ≈ 16px) и в контейнере, из-за чего фото на телефоне не доходит до краёв.

Добавляем в `<Lightbox>`:
- `carousel={{ finite: true, padding: 0, spacing: 0, imageFit: "contain" }}`
- В `styles` добавляем `slide: { padding: 0 }` и `container: { ..., padding: 0 }`

Так фото будет упираться в края экрана (с сохранением aspect-ratio через `imageFit: "contain"`), что и просил пользователь. Десктоп-вид от этого не страдает — там фото всё равно вписывается в окно по большей стороне.

### Технические детали

Файл один: `src/routes/destinations.bari.tsx`. Три точечные правки:
- строка ~284: `grid-cols-2` → `grid-cols-4` + `max-w-[70%]` на обёртке
- строка ~250: `w-[70vw] aspect-[4/3]` → `w-[45vw] aspect-square`
- строки ~645–661: добавить padding/spacing настройки в `Lightbox`

Никаких новых файлов, зависимостей, миграций. После правок — проверка в десктопе (1280+) и мобильном (375) viewport'ах.
