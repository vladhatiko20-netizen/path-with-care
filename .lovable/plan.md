## Что хочу сделать

Точечно добавить возможность детально рассмотреть фотографии — без затрагивания логики, маршрутов, данных и других секций. Меняется только два места в одном файле `src/routes/destinations.$slug.tsx`.

## 1. Галерея фотографий (десктоп и мобильная версия одновременно)

Сейчас при клике на миниатюру открывается lightbox (`yet-another-react-lightbox`) с плагинами `Thumbnails` и `Captions`. У этой же библиотеки есть официальный плагин **`Zoom`**, который добавляет:

- На десктопе — клик/двойной клик по фото для приближения, колесо мыши для плавного зума, перетаскивание мышью для панорамирования, кнопки `+`/`−` в тулбаре.
- На мобильном — pinch-to-zoom двумя пальцами, двойной тап для приближения, перетаскивание пальцем по увеличенному фото.

Решение: подключить плагин `Zoom` из той же библиотеки (она уже установлена, версия 3.32). Это одна строчка импорта и добавление `Zoom` в массив `plugins={[...]}`. Никаких новых зависимостей, никакого нового UI — просто расширяется уже существующий lightbox. Сломать ничего не может, потому что меняется только конфигурация одного компонента.

Опционально передам разумные настройки (`maxZoomPixelRatio: 3`, `zoomInMultiplier: 2`, `doubleTapDelay: 300`), чтобы поведение было плавным и предсказуемым.

## 2. Святыни — фото в модалке (десктоп)

Сейчас при клике на карточку святыни на десктопе открывается `Dialog`: слева квадратное фото, справа описание. По фото клик ничего не делает.

Решение: оборачиваю `<img>` слева в `<button>` с курсором zoom-in. Клик открывает то же фото в уже существующем `Lightbox` (отдельным состоянием `shrineLightbox`), с тем же плагином `Zoom`. Технически это переиспользование уже подключённого компонента — никаких новых библиотек, никаких изменений в данных святыни, никаких правок мобильного аккордеона.

Мобильный аккордеон святынь не трогаю — как вы и просили, там pinch-to-zoom на самом фото уже работает на уровне браузера.

## Что НЕ меняется

- Маршрутизация, лоадеры, серверные функции, схема Supabase.
- Главная страница, страница «Куда мы ездим», шапка, футер.
- Поведение карточек направлений (hover, zoom, переходы) — оставляем как есть.
- Мобильный аккордеон святынь, его анимация и скролл — не трогаем.
- Модалка святыни на десктопе — только добавляется клик по фото, текстовая часть и вёрстка идентичны.

## Технические детали (для разработчика)

Файл: `src/routes/destinations.$slug.tsx` — единственный изменяемый файл.

1. Добавить импорт:
   ```ts
   import Zoom from "yet-another-react-lightbox/plugins/zoom";
   ```
2. В существующем `<Lightbox … plugins={[Thumbnails, Captions]} />` дописать `Zoom`:
   ```tsx
   plugins={[Thumbnails, Captions, Zoom]}
   zoom={{ maxZoomPixelRatio: 3, zoomInMultiplier: 2, scrollToZoom: true }}
   ```
3. Добавить новое состояние и второй `<Lightbox>` для одиночного фото святыни:
   ```tsx
   const [shrineLightbox, setShrineLightbox] = useState<string | null>(null);
   ```
   В модалке святыни обернуть `<img>` в кнопку:
   ```tsx
   <button type="button" onClick={() => setShrineLightbox(s.image_url!)} className="w-full h-full cursor-zoom-in">
     <img … />
   </button>
   ```
   В конце компонента добавить второй `<Lightbox>` со слайдами из одного фото и теми же плагинами (`Captions`, `Zoom`).

Объём изменений: ~25 строк в одном файле, без новых зависимостей, без правок типов и без миграций.

## Что увидит пользователь

- В фотогалерее (десктоп и мобильный) появятся кнопки `+`/`−` в верхней панели lightbox, колесо мыши и pinch-to-zoom начнут работать, двойной клик/тап приближает.
- В модалке святыни на десктопе при наведении на фото слева курсор станет «лупа+», по клику фото откроется на весь экран с возможностью увеличения и перетаскивания.
