## Что меняем (только мобильная версия, `@media (max-width: 767px)` в `src/styles.css`)

### 1. Фон подписи — почти прозрачный с размытием
- `.yarl__slide_captions_container`: убрать сплошной чёрный фон, поставить `background: rgba(0,0,0,0.18)` + `backdrop-filter: blur(6px)` (Safari: `-webkit-backdrop-filter`). Текст остаётся белым, добавим лёгкую тень `text-shadow: 0 1px 2px rgba(0,0,0,0.6)` для читаемости поверх любой части фото.

### 2. Авто-скрытие стрелок и кнопок (показ только по касанию)
YARL рендерит навигацию (`.yarl__navigation_prev`, `.yarl__navigation_next`) и тулбар (`.yarl__toolbar` — лупа +/−, закрыть) поверх слайда. На мобильном:

- По умолчанию: `opacity: 0; pointer-events: none; transition: opacity .25s ease`.
- Когда корень лайтбокса получает класс `lb-controls-visible` — `opacity: 1; pointer-events: auto`.

Класс переключается из `src/components/site/LightboxCaption.tsx`: добавим небольшой эффект, который в мобильном режиме навешивает обработчик `pointerdown` на `.yarl__container`, добавляет класс `lb-controls-visible` к контейнеру лайтбокса и снимает его через таймаут ~2.5 с (таймер сбрасывается при каждом касании). На десктопе поведение не меняется.

Альтернатива без JS (не выбрана): CSS `:hover` не работает на тач-устройствах надёжно — стрелки либо останутся скрытыми, либо «залипнут» после первого тапа. Поэтому нужен JS-таймер.

### 3. Десктоп не трогаем
Все правила — внутри `@media (max-width: 767px)`. Десктопная подпись под фото (`.lb-desktop-caption`) и постоянно видимые контролы остаются как есть.

## Технические детали

Файлы:
- `src/styles.css` — мобильные правила для `.yarl__slide_captions_container`, `.yarl__navigation_prev`, `.yarl__navigation_next`, `.yarl__toolbar`, плюс класс `.lb-controls-visible` на корне.
- `src/components/site/LightboxCaption.tsx` — небольшой хук/эффект, который в мобильном режиме добавляет/снимает класс `lb-controls-visible` на `.yarl__container` по тапу с автоскрытием через 2.5 с.

Риски: если пользователь захочет перелистнуть фото, ему нужно сначала тапнуть для появления стрелок (либо использовать свайп — YARL поддерживает свайпы по умолчанию, так что навигация без стрелок остаётся доступной).
