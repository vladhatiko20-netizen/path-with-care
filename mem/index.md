# Project Memory

## Core
Сайт PALOMNIK — православные паломнические поездки из Кишинёва, подразделение SRL Eldorado Tur.
Тон: тихий, тёплый, без коммерческой агрессии. Никаких восклицательных знаков, "скидок", "горящих туров".
Палитра: крем #f7f1e3, песок #ede4d0, золото #c9a96e, терракота #a04826 (очень редко), глубокий коричневый #3d2817.
Шрифты: Cormorant Garamond (заголовки), Crimson Pro (текст). Никаких sans-serif в основном тексте.
Языки: RU (по умолчанию) и RO, переключатель в шапке, выбор хранится в localStorage.
