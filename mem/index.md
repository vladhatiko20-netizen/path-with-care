# Project Memory

## Core
Сайт ПАЛОМНИК / PELERIN — православные паломнические поездки из Кишинёва, подразделение SRL Eldorado Tur.
Тэглайн: «И вместе ко Христу» / „Și împreună spre Hristos”. Логотип: ☦ + ПАЛОМНИК + сабтекст «Паломнические поездки из Кишинёва».
Тон: тёплый, домашний, без коммерческой агрессии. Никаких восклицательных знаков, «скидок», «горящих туров». Слово «тихий» НЕ использовать.
На главной Анна не упоминается лично — она появляется только на /about. Главная — про сами поездки.
Палитра: крем #f7f1e3, песок #ede4d0, золото #c9a96e, терракота #a04826, глубокий коричневый #3d2817.
Шрифты: Cormorant Garamond (заголовки), Crimson Pro (текст). Никаких sans-serif в основном тексте.
Языки: RU (по умолчанию) и RO, переключатель в шапке, выбор хранится в localStorage.
